# Java-Cargo-Automation-System
A Java Swing-based logistics management system designed with OOP principles, featuring role-based access and system analysis diagrams.

## Key Technical Features
- **Architecture:** Modular Object-Oriented Programming (OOP).
- **GUI:** Interactive user interface developed with Java Swing.
- **Analysis:** Comprehensive system documentation featuring **Use-Case, Sequence, and Class diagrams**.
- **Core Concepts:** Implementation of **Inheritance, Abstraction, and Encapsulation**.
